## Connected Preview 1.6.0-preview.9

The preview connects model APIs, browser tools and Connect My Bot. Preview.9 simplifies AI setup to choose a provider, paste an API key and Connect. Advanced models, local servers and CMB rooms are optional. It also adds automatic Mac replacement, restart and installer ejection. The Launch tab, workspaces, selected-tab research, Earth home screen and five product shortcuts remain included. Chat-app subscriptions and API billing are separate.

The Mac preview is ad-hoc signed for bundle integrity, without Apple Developer ID signing or notarization. macOS may still block it. Windows is unsigned. There are no Intel Mac, Windows ARM64 or Linux installers in this release. See the release notes for installation steps and verification details. Each release includes SHA-256 checksums.

**Update browser** checks this repository and downloads a newer release. Both installed platforms offer **Restart and install** after you save unfinished work. On Mac, the browser stages and verifies the replacement, ejects the installer, closes normally, replaces its app and reopens. Use a writable installed copy owned by your account. **Preview.8 and earlier need one last manual replacement to get this new updater.** Initial Mac installation still uses drag-to-Applications. Apple Developer ID signing and notarization remain pending.

This public repository distributes installers and release information. The canonical [browser source](https://github.com/tmwdigitalllc/xwebpilot) and [Windows source mirror](https://github.com/tmwdigitalllc/xwebpilot-windows) are private and require repository access.
